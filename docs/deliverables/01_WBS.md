## 권장 순차 일정

기존 계획의 13~17주 추정은 조직 승인·실데이터 연동·UAT를 포함한 1인 기준이다. 코드 기준선은 구현했지만 아래 운영 일정은 별도 확보한다.

| 주차 | 운영 작업 | 종료 조건 |
|---|---|---|
| 1 | staging 프로젝트·비밀키·App Hosting 준비 | 합성 데이터만으로 배포 가능 |
| 2 | 검사기관 샌드박스 계약 테스트 | 서명·멱등·오류 응답 합의 |
| 3 | 정상범위·정책 승인본 등록 | 버전·승인자·승인일 기록 |
| 4 | 기관 UAT 및 접근권한 점검 | 역할별 체크리스트 서명 |
| 5 | 장 기능 제한 활성화 | 오류율·지원요청 기준 충족 |
| 6 | 혈액 기능 제한 활성화 | 단위/검토대기 지표 기준 충족 |
| 7 | 통합 인사이트 활성화 | 누락축·정책 버전 재현 확인 |

## 변경 보존

- 기준 커밋: `363a9bc chore: preserve integrated care UI baseline`
- 기준선 이후 변경은 기능별 커밋으로 관리한다.
- 사용자 변경을 되돌리는 `reset --hard`, 광범위 삭제는 수행하지 않는다.
