# D-FET 통합 케어 수동 UAT 체크리스트

기준일: 2026-08-10

대상: iOS 우선, Android 동등 검증

데이터: 합성 데이터만 사용

자동 테스트 통과는 이 문서의 수동 확인을 대체하지 않는다. 검사기관 계정, 기관 승인 정책, 실기기 카메라·QR, 실제 접근성 도구가 필요한 항목은 담당자가 날짜와 결과를 기록한다.

## 1. 공통 셸·접근성

- [ ] 게스트 케어유형 선택 → 가입 → 로그아웃/재로그인 후 값 유지
- [ ] 기존 회원 최초 1회 케어유형 확인과 내정보 변경
- [ ] 오늘·기록·리포트·내정보 4탭의 스크롤/뒤로가기 상태 유지
- [ ] light/dark/system에서 OS 테마 전환 추종
- [ ] 320/390/430px, 글자 배율 1.0/1.3/2.0에서 주요 값과 CTA 미절단
- [ ] VoiceOver/TalkBack에서 4축 이름·상태·리본 펼침 상태 전달
- [ ] 동작 줄이기 사용 시 등장·펄스 모션이 즉시 완료 상태로 표시

## 2. Today Signal·효능감

- [ ] 이전 스냅샷 대비 변화 문장이 점수보다 먼저 표시
- [ ] 운동·식단·장·혈액 축을 탭하면 색·수치·설명이 함께 전환
- [ ] 오늘의 한 가지 완료/취소와 햅틱 피드백
- [ ] 완료 상태가 재실행 후 유지되지만 임상 점수에는 반영되지 않음
- [ ] 축 데이터가 부족하면 임의 값 대신 기존 기록형 홈 또는 누락 상태 표시

## 3. 장내미생물 16S

- [ ] Shannon, Simpson, Chao1, Observed OTUs 원수치 표시
- [ ] Phylum 구성과 Genus 전문가 상세
- [ ] Bray-Curtis PCoA, weighted/unweighted UniFrac 전문가 접근
- [ ] 일반 회원의 expert 경로·문서 접근 차단
- [ ] Evidence Ribbon에 검사기관 출처, 알파 수신 범위, 정책 버전 표시
- [ ] 미승인 정책에서 점수 대신 `산정 준비 중`
- [ ] 리본 펼침 시 소비자/전문가 분리와 비진단 안내 확인

## 4. 혈액 POCT

- [ ] ALT, AST, TBIL, DBIL, TP, ALB, UREA, CRE, UA, GLU, TG, CHOL, HDL-C 표시
- [ ] 간·신장·대사/혈당·지질 4패널과 패널 완성도
- [ ] 부분 데이터에서 수신 개수와 누락 상태 표시
- [ ] 미지원 단위를 자동 변환하지 않고 검토 대기로 표시
- [ ] 2회 이상 검사에서 같은 표준 코드·단위만 추이 비교
- [ ] 관리자·검사자 QR/UDI, Lot, 유효기간 스캔/직접 입력
- [ ] Evidence Ribbon에 정규화 출처, 13종 수신 범위, 정책 버전 표시

## 5. 4축 통합 인사이트

- [ ] 운동·식단·장·혈액 전체 스냅샷의 점수·레이더·타임라인
- [ ] 일부 축 누락 시 완성도와 누락 축 표시, 0점 보간 금지
- [ ] 이전 스냅샷 대비 동일 정책 비교
- [ ] 새 검사 수신 뒤 새 스냅샷 생성과 정책 버전 추적
- [ ] 축간 문구가 인과 단정 없이 `함께 관찰됨`/`연관 가능성`으로 제한
- [ ] Evidence Ribbon의 기준시점·완성도·정책과 펼침 설명 확인

## 6. 관리자·권한

- [ ] admin: 사용자·배정·요청·콘텐츠·검사·정책·감사 전체 범위
- [ ] trainer: 담당 회원 소비자/전문가 리포트만 접근
- [ ] 비담당 trainer: 회원·전문가 리포트 차단
- [ ] lab_operator: 수집·오류 수정만 허용, 회원 기록·전문가 리포트 차단
- [ ] 승인 정책 수정 금지와 새 버전 게시/활성 전환
- [ ] JSON/CSV 업로드와 외부 API가 같은 검증 오류·멱등 결과 반환
- [ ] 브라우저에 서비스 계정·HMAC 비밀키·관리자 자격증명 미노출

## 7. 실기기·운영 게이트

- [ ] iOS 실기기 카메라/사진/자세평가 권한 거부·영구 거부·복귀
- [ ] Android 실기기 카메라/사진/뒤로가기 동등 동작
- [ ] staging 검사기관 HMAC 서명·타임스탬프·키 회전 계약 테스트
- [ ] 실제 건강데이터 보존·삭제·동의 정책 기관 서면 승인
- [ ] 정상범위·가중치·생활가이드 승인본과 승인자·승인일 기록
- [ ] 장 → 혈액 → 인사이트 순 점진 활성화와 각 단계 롤백 훈련
- [ ] 개인정보 고지, 앱 서명, 스토어 심사, 장애 알림 담당자 확인
