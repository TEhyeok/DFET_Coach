## 🐛 버그 재현 테스트

### Bug #1: 메모리 누수
**재현 방법**:
1. 자세 평가 시작 → 종료 (10회 반복)
2. DevTools > Memory에서 메모리 그래프 확인
3. **예상**: 메모리가 계속 증가 (해제 안 됨)

**확인 방법**:
```
DevTools URL: http://127.0.0.1:9101?uri=http://127.0.0.1:62245/1BXygZ-oy9I=/
Memory 탭 > Record 버튼 클릭
```

### Bug #2: Race Condition (AI 분석)
**재현 방법**:
1. 음식 사진 선택
2. "AI 분석" 버튼 2번 빠르게 연타
3. **예상**: 두 번째 결과가 첫 번째를 덮어쓸 수 있음

**확인 방법**:
- 콘솔 로그에서 API 호출 횟수 확인
- 결과가 이상하게 표시되는지 확인

### Bug #6: 네트워크 타임아웃
**재현 방법**:
1. Wi-Fi를 매우 느린 속도로 설정 (또는 네트워크 조절)
2. AI 분석 실행
3. **예상**: 무한 로딩 (타임아웃 없음)

**확인 방법**:
- 30초 이상 대기
- 앱이 멈추는지 확인
- 강제 종료 가능한지 확인
