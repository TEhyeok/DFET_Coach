## 최종 범위 판정

- 과업지시서의 개발 범위는 화면·소스·자동시험·빌드 증빙으로 대응한다.
- 16S FASTQ/QIIME 파이프라인과 기존 SwiftUI 트레이너 UI 개편은 확정 제외 범위다.
- 기관 승인 및 실서비스 계정이 필요한 항목은 완료로 과장하지 않고 외부 운영 게이트로 명시했다.
