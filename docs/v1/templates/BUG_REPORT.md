## 사용법

- 이슈 폼 [bug.yml](../../../.github/ISSUE_TEMPLATE/bug.yml)(GH-05)이 이 템플릿과 같은 필드를 가진다. 폼을 못 쓸 때(예: 스프린트 추적 이슈에서 옮길 때) 아래 마크다운을 이슈 본문에 붙인다.
- 백로그 키는 소유자가 붙인다(해당 단계 대역의 다음 번호). 같은 스프린트에 병합한 스토리의 결함이면 새 버그 대신 그 스토리 이슈를 다시 연다.
- **재현은 합성 데이터로만** 한다. 실제 회원 이름·사진·수치·uid·이메일이 들어간 스크린샷, 로그, 내보내기 파일을 붙이지 않는다. 필요한 경우 값을 가린 뒤 붙인다.
