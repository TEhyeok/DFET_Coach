## 사용법

- 작업일마다 18:00에 5분, 스프린트 추적 이슈 `[SNN] 진행 기록`에 코멘트 1건을 남긴다([ASM-01-10](../01_AGILE_WORKING_AGREEMENT.md#가정과-스파인-차이-기록)).
- 목적은 세 가지다: 금요일 리뷰·회고의 사실 근거, 차단 요소 조기 발견, P1a 이후 **자체 사용 기록**(PRD §12.1 '2주 이상 자체 사용')의 근거.
- 에이전트는 이 이슈에 쓰지 않는다. 에이전트의 보고는 각 스토리 이슈의 '완료 보고'에 있다.

## 템플릿

```markdown
### YYYY-MM-DD(요일) · SNN 작업일 <k>/<n>
- 병합: DF-NNN(#PR), … | 없음
- 검토 중: DF-NNN(#PR, <검토 상태>) … (In review <n>/3)
- 에이전트 진행: claude → DF-NNN(<상태>), codex → DF-NNN(<상태>) (브랜치 <n>/3)
- 소유자 행동: DF-9NN <진행 내용> | 없음
- 차단: <무엇이, 누가 풀어야, 언제까지> | 없음
- 자체 사용(P1a~): 세션 <n>건 기록, syncFailed <n>건(모두 표시됨: 예/아니오), 유실 <n>건 | 해당 없음
- 내일: <가장 중요한 1~2개>
```

## 예시

```markdown
### 2026-09-29(화) · S01 작업일 2/5
- 병합: DF-003(#12)
- 검토 중: DF-004(#13, 생성기 Dart 출력 재작업 요청 1회) (In review 1/3)
- 에이전트 진행: claude → DF-008(xcodegen 골격, 시뮬레이터 빌드 통과), codex → DF-005(레거시 픽스처 작성 중) (브랜치 2/3)
- 소유자 행동: DF-903 Firebase 콘솔 iOS 앱 등록 완료, plist는 저장소 밖 보관
- 차단: 없음
- 자체 사용(P1a~): 해당 없음
- 내일: DF-004 재검토, DF-908 법률 자문 의뢰서 발송
```

## 쓰지 않는 것

- 회원 이름, 연락처, 건강 수치, 사진, 서명, 초대 코드 원문 등 실데이터(자체 사용 중이라도 건수만 적는다).
- 비밀 값, 콘솔 화면의 키·토큰, 법률 의견서 내용.
- 추측성 평가("에이전트가 느리다"). 사실(시간, 횟수, 링크)만 적는다.
