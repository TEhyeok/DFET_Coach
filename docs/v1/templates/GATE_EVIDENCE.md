## 사용법

- 게이트마다 파일 하나: `docs/v1/evidence/<게이트 ID>.md`(예: `G-01.md`, G-05a·G-05b·G-07a는 그대로 `G-05a.md` 등). 플래그 개방 체크리스트는 같은 폴더의 `flags-<키>.md`다([V1-01 ASM-01-11](../01_AGILE_WORKING_AGREEMENT.md#가정과-스파인-차이-기록), [V1-03 ASM-03-11](../03_RELEASE_AND_SPRINT_PLAN.md)).
- 소유자 행동 이슈(owner_action.yml, GH-07)가 끝날 때마다 해당 게이트 파일의 증빙 표를 갱신한다. 매주 수요일 게이트 점검에서 상태를 확인한다.
- 게이트 판정은 소유자만 한다. 에이전트는 CI 결과 링크 모음 같은 **코드 측 증빙 요약**만 준비할 수 있다(G-03).

## 저장소에 적어도 되는 것과 안 되는 것

| 적는다 | 적지 않는다(저장소 밖 보관) |
|---|---|
| 증빙의 존재, 날짜, 문서 제목·파일명, 발행 주체(기관명), 판정 결과 요지 | 법률 의견서·식약처 회신·IRB 승인서 원문, 계약서 |
| CI 실행 링크, 태그, 커밋 SHA | 콘솔 화면의 키·토큰·plist 값·서비스 계정 정보 |
| 처리방침 공개 URL(공개 문서) | 참여자·회원 명단, 서명, 연락처 |
| 리전 이름, 설정 여부(예/아니오) | 실데이터 수량을 넘는 내용(수량 보고만) |
