## 사용법

- 단계 마지막 스프린트 금요일 13:30에 60분 검토한다(리뷰·데모 15:00 전). 기록 파일은 `docs/v1/reviews/PHASE_<P0|P1a|P1b|P2|P3>_EXIT.md`다.
- 판정은 **통과 / 조건부 통과 / 불통과** 중 하나다. 불통과면 다음 단계로 넘어가지 않는다(PRD §12.7). 조건부 통과는 미충족 항목·기한·담당을 적고, 그 항목이 다음 단계의 플래그 개방이나 실데이터 투입을 막지 않을 때만 허용한다.
- 측정 전 지표는 '측정 전'으로 적는다. 가설 목표는 이번 측정으로 다시 정해 PRD 변경 이력 반영을 제안한다.
- 개인정보: 지표는 건수·비율·구간만 적는다. 회원 식별 정보나 건강 수치 원값을 적지 않는다.

## 단계별 종료 기준 요약

PRD §12.1의 종료 게이트를 옮긴 것이다. 원문이 우선한다.

| 단계 | 종료 기준 |
|---|---|
| P0 | G-01, G-02, G-03. SOAP v2 교차 왕복 테스트 통과. 금지어 린트 CI 통과(출시 앱 문자열 포함) |
| P1a | M-01 평균 10초 미만, M-02·M-08·M-11 측정. 데이터 유실·알리지 않은 저장 실패 0건, 금지어 노출 0건. 2주 이상 자체 사용 |
| P1b | M-04a/b, M-03, M-05(조건 사유) 측정. M-G5 검토(초과 시 §6.4.4 축소 절차). 유실 0건 |
| P2 | 공유·해제 E2E(회원은 memberSummaries만). 담당 변경·탈퇴 삭제 연쇄 테스트. M-06·M-07·M-09·M-10 측정. G-07 예비 결과. 베타 유지·해제 판단 |
| P3 | 가설 목표 4주 유지, 중대 개인정보 사고 0건, 규칙 테스트 100%. PRD v1.1 발행 |
